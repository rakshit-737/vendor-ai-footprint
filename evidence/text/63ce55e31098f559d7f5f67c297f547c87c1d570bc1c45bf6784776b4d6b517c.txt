VII. Automic and SAP Deployment Scenarios

Automic and SAP On-Premises:

Multiple agents deployed on-premises or in the cloud

Certified SAP agent orchestrates SAP

OS agent handles file transfer (data in/out of SAP)

SAP Rise with Automic:

SAP system moves to the cloud (private cloud edition/SAP Cloud ERP Private Edition or public cloud version)

SAP does not allow third-party software (including Automic agent) in the SAP environment itself

Automic’s SAP agent continues to work (APIs supported, fully certified for this scenario)

Choice to deploy SAP agent on-premises or in the cloud

Same for Automic SaaS

Alternative options for moving data (since Automic OS agent cannot be in SAP environment):

Secure FTP

NFS file share mounts

Cloud storage (S3 and other leading cloud vendors)

Automic SAP Agent in the Cloud with Automic SaaS:
