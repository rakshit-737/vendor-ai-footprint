Software Engineer

Join Team FSSI and Become an Employee-Owner!

Who We Are:

Opening its doors over 45 years ago, FSSI is a leading document outsourcing company servicing Fortune 500 companies in the financial, banking, insurance and billing industries across the U.S. We are currently looking for a Software Engineer to join our Application Development team at one of our East coast facilities - Orlando, Florida or Lincoln, Rhode Island.

This role supports the development and maintenance of production applications, web-based solutions, APIs, and composition templates used to generate client document output for physical print and mail or electronic presentment. The role contributes to full stack application development, code changes, data mapping, system integrations, and template updates while gaining experience with modern .NET technologies, web development frameworks, cloud services, DevOps practices, and secure coding standards that ensure application integrity, scalability, and maintainability.

Our ideal candidate is a self-starter who enjoys figuring things out, taking ownership, and getting things done. They are naturally curious, resourceful, and comfortable jumping into new challenges without needing step-by-step direction. They come prepared with ideas and questions to engage in team discussions and thrive in an environment where initiative and adaptability are valued. If you’re a problem solver who is looking to make a meaningful impact, we want to hear from you!

The schedule for this job is Monday - Friday, 8:00 am – 4:30/5:00pm. After an initial 90-day onsite training period, you will have the option to work a hybrid schedule (1/2 days remote and 3 days in office).

Your Essential Duties:

Analyze project requests and identify required updates to applications or templates.

Lead discussions with internal stakeholders and clients to design and implement robust applications and templates aligned with production workflows and business needs.

Interpret structured input data and understand record layouts and data relationships.

Perform accurate data mapping aligned with client and output specifications.

Develop, update, and maintain C# applications using .NET and .NET Core / ASP.NET Core, including reusable libraries and common code components.

Design, develop, consume, and troubleshoot RESTful APIs and JSON-based integrations using ASP.NET Core Web API and related technologies.

Work with relational databases such as Microsoft SQL Server, including SQL queries, stored procedures, data access using Entity Framework Core or similar ORM technologies, and basic database performance considerations.

Modify and maintain templates using composition tools such as OpenText Exstream, or Quadient Inspire.

Insert and configure data variables and apply basic logic in templates.

Write clean, maintainable, testable code using object-oriented principles, SOLID practices, dependency injection, and secure development standards.

Submit well-structured Git merge requests and participate in peer code reviews.

Work closely with QA and DevOps teams to support testing, CI/CD pipelines, deployment, monitoring and validation processes.

Use automated testing practices and frameworks such as xUnit, NUnit, or equivalent tools to support application quality and regression testing.

Participate in application deployments and cloud-based development practices, including familiarity with AWS services, containers such as Docker, and modern observability/logging tools.

Assist in resolving issues affecting production and contribute to timely support and fixes.

Ensure all changes are aligned with FSSI’s application development standards and production best practices.

Develop and maintain integrations with internal common code, RESTful APIs, web services, databases, and third-party services supporting application functionality.

Apply basic knowledge of USPS mailing requirements and print production standards to ensure template and output compliance.

Requirements

What You Bring:

Bachelor’s Degree in Computer Science, Software Engineering, Information Technology or a related field strongly preferred.

1–2 years of experience in software engineering, full stack application development, API development or document composition preferred.

Strong foundation in C#, object-oriented programming and modern .NET development, including .NET Core / ASP.NET Core.

Working knowledge of ASP.NET Core MVC and/or Razor Pages, Web API development, dependency injection, configuration, authentication, and authorization concepts.

Familiarity with Microsoft SQL Server and data-access technologies such as Entity Framework Core, LINQ, and SQL.

Understanding of REST APIs, JSON, HTTP, API authentication, and integration patterns.

Exposure to unit and integration testing frameworks, CI/CD concepts, and DevOps tooling such as GitLab CI/CD, GitHub Actions, Azure DevOps, or equivalent platforms.

Exposure to cloud and container technologies such as AWS and Docker is preferred.

Understanding of modern application security concepts, including OWASP secure coding practices, identity/access management, secrets management, and protection of sensitive data.

Understanding of structured data formats, record layouts, and data mapping.

Experience with composition tools (e.g., OpenText Exstream, or Quadient Inspire).

Familiarity with Git workflows, branching and merge requests, secure coding practices, debugging, unit testing, and code review techniques.

Strong attention to detail, problem-solving skills, and a collaborative mindset.

Ability to follow processes and apply feedback to improve code quality.

Familiarity with postal requirements and mailing software concepts, including address formatting, barcodes, and mailpiece design best practices is a plus.
