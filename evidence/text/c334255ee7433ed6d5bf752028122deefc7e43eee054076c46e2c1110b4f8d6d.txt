Sr. Software Engineer

Position summary:

The Clearing House (TCH) is seeking a Senior Software Engineer to join our RTP Product Engineering team. As a senior member of the team, you will be responsible for designing, developing, and enhancing our critical real-time interbank payment platform, including development of new applications and features while improving the functionality, reliability, and performance of existing applications. The Senior Software Engineer works directly with RTP Product teams and the Director of Product Engineering to ensure quality deliverables are completed on time and in accordance with TCH standards. The Senior Software Engineer also works closely with Operations and Technology to define and implement new maintainability features and to ensure system resiliency.

This role is well suited for an experienced engineer who enjoys solving complex technical problems, building highly reliable systems, and delivering innovative applications that operate at the core of financial infrastructure. The organization is actively transforming its payment platforms toward cloud-native, distributed architectures while introducing modern automation and AI-assisted engineering practices into its software development lifecycle.

TCH values engineers who are technically curious, pragmatic, and interested in understanding how complex systems work, end to end. The ideal candidate will be a hands-on software engineer who has strong Java development experience, deep expertise in distributed application architectures, and an avid interest in building critical systems where performance, security, resiliency, and sustainability are vital for success.

Essential functions and responsibilities:

Design, develop, test, and maintain highly reliable software supporting real-time payment processing

Serve as a senior technical contributor across the complete software development lifecycle

Develop software components primarily in Java, leveraging frameworks such as Spring and Spring Boot

Develop critical applications using AWS cloud-native services and event-driven architectures, including containerized and serverless stacks for streaming data and real-time messaging

Develop Python scripts and programs as needed for data automation and integration services

Design and implement services and APIs using modern software engineering principles and patterns

Participate in architecture and technical design decisions involving scalability, availability, resiliency, security, and maintainability

Develop and maintain automated build, test, deployment, and infrastructure processes using CI/CD pipelines for engineering and software quality automation

Apply Infrastructure as Code practices for cloud deployments using software tools such as Terraform

Apply observability, monitoring, fault handling, and operational readiness practices appropriate for mission-critical systems

Participate in troubleshooting and root-cause analysis of complex application and production issues

Mentor less experienced engineers and contribute to engineering standards, secure development practices, peer code reviews, and architectural best practices.

Work closely with product, architecture, infrastructure, security, operations, and other engineering teams, following an agile development methodology as part of a scrum team

Use approved AI-assisted development tools to improve software design, development, testing, documentation, and engineering productivity while following enterprise SDLC and security controls.
